Local Android Emulator

Boots an Android-x86 image you provide, entirely on your machine, using the v86 x86 emulator.

1. Your image

Files are read locally and never uploaded.

2. Machine

3. Emulator files (advanced)

Needs build/libv86.js, build/v86.wasm, bios/seabios.bin, bios/vgabios.bin. For fully offline use, download them into a folder next to this page and set this to ./v86.

Tips

  • Open this page over http, not file:// (browsers block WebAssembly from file URLs). In its folder run python3 -m http.server 8000, then visit localhost:8000/android-emulator.html.
  • Use an Android-x86 ISO (e.g. 9.0-r2). At the boot menu choose Live CD – VESA mode, or "Debug mode" if the screen stays black.
  • Expect slow boot (minutes). This is software emulation, not hardware-accelerated.
  • Click the screen to capture the mouse; Esc releases it and exits fullscreen.
